Where this data comes from

Every figure on this page is fetched live in your browser. Nimbus cross-checks two independent providers so you can see they agree, and can add Google's own Weather API if you have a key.

  • Open-Meteo — primary source. Blends ECMWF, NOAA GFS and DWD ICON models. No key.
  • MET Norway — independent national met service (yr.no). No key.
  • Google Weather API — optional, needs your own key (below).

Not configured — the app works fully without it.

The key is stored only in this browser. Because it is used client-side, restrict it in Google Cloud to your own website's address (HTTP referrer) and enable only the Weather API. Google Weather requires a billing-enabled Maps Platform project and may incur charges.
